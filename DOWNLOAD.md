# Download und Installation

Repository:

```text
https://github.com/florianthepro/csv-reporting
```

Installation oder Verwaltung:

```bash
curl -fsSL https://raw.githubusercontent.com/florianthepro/csv-reporting/main/setup.sh | sudo bash
```

Vorher im Repository ergänzen:

```text
frontend/index.svg
frontend/edit.svg
```

Nach der Installation zeigt das Setup die HTTPS-Adresse. Beim ersten Webaufruf wird im Editor die CSV-Quell-URL eingetragen. Das CA-Zertifikat für intern signiertes HTTPS kann anschließend im Editor unter **Allgemein** heruntergeladen werden.
