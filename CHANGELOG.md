# Changelog

## 1.0.0 - 2026-10-23

- Added CSV loading, parsing, cache and index/map/raw/edit views.
- Added filters, rules, column selection, renaming, links and download filters.
- Added atomic debounced autosave with revision conflict protection.
- Added current, wrapped and legacy configuration import.
- Added legacy rule escape decoding and disabled-rule reconstruction.
- Added import statistics and explicit invalid-rule reporting.
- Added versioned app manifest and authenticated management adapter.
- Added health, backup-range, restore-validation and capability endpoints.
- Added unit, API, import, migration, autosave and multi-instance tests.
